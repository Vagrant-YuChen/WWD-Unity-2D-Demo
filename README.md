## 中文 / Chinese

### 下载与安装

请到 GitHub Releases 页面下载发布版本：

https://github.com/Vagrant-YuChen/WWD-Unity-2D-Demo/releases/tag/v1.0

#### Windows 版本
1. 下载 `Windows.zip`（约 123 MB）。
2. 解压到任意文件夹。
3. 双击运行 `WackyWorldDash.exe` 即可进入游戏。

#### WebGL 网页版
1. 下载 `WebGL.zip`（约 90 MB）。
2. 解压到任意文件夹。
3. **重要**：不要直接双击打开 `index.html`。WebGL 构建必须通过 HTTP 协议加载才能运行，直接双击会卡在加载或无法启动。
4. 推荐方法：将解压后的文件夹放到支持 HTTP 的服务器上，或者在本地用 Python / Node.js 等工具启动一个简单的 HTTP 服务器，然后用浏览器访问 `index.html`。

### 存档与金币

## English

### Download & Install

Please download the release from GitHub Releases:

https://github.com/Vagrant-YuChen/WWD-Unity-2D-Demo/releases/tag/v1.0

#### Windows Version
1. Download `Windows.zip` (~123 MB).
2. Extract to any folder.
3. Double-click `WackyWorldDash.exe` to launch the game.

#### WebGL Web Version
1. Download `WebGL.zip` (~90 MB).
2. Extract to any folder.
3. **Important**: Do NOT double-click `index.html` directly. The WebGL build must be loaded via HTTP to run; opening it directly will get stuck at loading or fail to start.
4. Recommended: place the extracted folder on an HTTP server, or run a simple local HTTP server (e.g. with Python / Node.js), then open `index.html` in your browser.

### Save & Coins
- Coins and level progress are saved locally on your computer.
- To reset total coins, use `Tools > Wacky World Dash > Reset Total Golden Coins` in the Unity Editor. It is recommended to reset before building so new saves start from 0.

### Gameplay
Gameplay instructions are provided in-game. Please check the in-game text; not repeated here.
